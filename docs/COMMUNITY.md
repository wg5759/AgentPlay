# AgentPlay 社区参与

AgentPlay 希望把真实使用问题转成可验证、可恢复、可维护的改进，而不是用虚假活跃度包装项目。

## 参与入口

- 在 [Q&A](https://github.com/wg5759/AgentPlay/discussions/categories/q-a) 提使用问题。
- 在 [Ideas](https://github.com/wg5759/AgentPlay/discussions/categories/ideas) 描述真实工作流与预期结果。
- 在 [Show and tell](https://github.com/wg5759/AgentPlay/discussions/categories/show-and-tell) 展示你有权公开的成果。
- 对可复现缺陷提交结构化 Issue。
- 准备代码前阅读 [CONTRIBUTING.md](../CONTRIBUTING.md)，优先从一个小而完整的纵向改进开始。

## 证据与公开采用

浏览量、克隆量、维护者自己创建的 Issue/Discussion、CI 机器人和 Dependabot 活动都不等于真实用户采用。项目只把下列公开信号当作外部采用证据：

- 非维护者描述的真实使用场景、问题或成果；
- 可核对的外部文章、教程、演示或独立讨论；
- 外部贡献者提交并通过审查的 Issue、PR 或复测回执；
- 机构或社区公开说明的使用、赞助或支持。

这条边界同样适用于后续代码签名申请：社区入口可以由维护者建设，但采用证据必须来自真实外部参与，不能伪造。

## 行为与隐私

参与者应尊重他人，围绕技术事实和可复现结果讨论，不骚扰、不歧视、不发布无权公开的素材。所有参与同时受 [CODE_OF_CONDUCT.md](../CODE_OF_CONDUCT.md)、[PRIVACY.md](../PRIVACY.md) 与 [SECURITY.md](../SECURITY.md) 约束。
