# 播放后的窗口占用修复（2026-09-04）

实现提交：`6493f01`（本地分支 `agent/0.9.1-window-mode-20260904`）。

## 已验证问题

旧安装版在进入全屏后关闭视频，真实回读为 `fullscreen=true, theater=true, video=false`。关闭入口只清媒体，没有退出系统全屏；播放器组件又已经卸载，不能依赖它继续恢复窗口。

没有把“刚打开就自动全屏”当成已证实事实；本轮确定复现的是关闭残留，并同时改善默认窗口和退出操作。

## 本轮实现

- 启动窗口按工作区约80%选取，并处理高DPI、小屏和负坐标屏幕，保留合理上下限，不再简单贴近桌面边缘。
- 关闭媒体先退出原生全屏，再清空媒体及影院/全屏状态。
- 实际播放结束自动退出影院/原生全屏；手动暂停不会自动缩小。
- 全屏有不随控制条淡出的“退出全屏 · Esc”按钮。
- 双击进度条、按钮等控件不再冒泡触发全屏；显式视频双击、全屏按钮及快捷键保留。
